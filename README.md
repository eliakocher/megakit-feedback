# MegaKit Feedback

MegaKit puts three small tools on your Mac: **MegaClick** (more in Finder's right-click menu, and ⌘X/⌘V for files), **MegaIntelligence** (an AI panel for your files, with ⌥Space) and **MegaCorners** (screen corners that run actions).

This repository holds no code. It is where you tell us what to fix and what to build:

- **Something broken?** [Report a bug](https://github.com/eliakocher/megakit-feedback/issues/new?template=bug_report.yml)
- **An idea?** [Request a feature](https://github.com/eliakocher/megakit-feedback/issues/new?template=feature_request.yml)
- **A question?** [Start a discussion](https://github.com/eliakocher/megakit-feedback/discussions)

Before you open a new issue, please search the existing ones; a 👍 on an issue counts as a vote.

From inside the app: menu bar → **Report a Bug…** or **Request a Feature…** fills in your MegaKit and macOS versions for you.
